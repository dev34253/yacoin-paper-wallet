Generate

Create a new paper wallet.

Keys come from your browser's cryptographically secure random number generator (crypto.getRandomValues). Any extra randomness you add is hashed in with it, so it can only make keys stronger.

Move your mouse around the page for a while to mix in more: 0%

Each wallet gets its own independent key. Printing puts several per page.

Verify

Check a key or address.

Paste a YACoin private key (WIF or 64-character hex) to see the address it controls, or paste an address to check that it's valid. Use this to confirm a printed wallet before you send coins to it.

How to use

Safe cold storage in six steps.

A paper wallet is only as safe as the computer that made it. Follow these steps for coins you care about.

Save this page

Save this single HTML file to a USB stick. It has no external files and makes no network requests.

Go offline

Open it on a computer that's disconnected from the internet. A live USB OS like Tails is ideal.

Generate & print

Generate a wallet, then print it on a printer connected by cable, not over Wi-Fi or a cloud print service.

Verify

Type the printed private key into Verify and check that it shows the same address. Then close the browser.

Fund it

Send YAC to the public address. You can check the balance any time on a block explorer using only the address.

Spend (sweep)

In YACoin Core, open Help → Debug window → Console and run importprivkey "YOUR_WIF" "paper" true. Then send the funds on and stop using the paper key.

Keep the private key secret. Anyone who sees or scans it can take the coins, and there's no way to undo that. Store the paper somewhere dry and private, and consider making a second copy. If you lose the paper, the coins are gone for good.
